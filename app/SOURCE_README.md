# 文件搜索 v0.10：源码试用包

这是源代码，不是可直接拖入“应用程序”的安装包。请先在接收者自己的 Mac 上编译，再安装生成的应用。

## 适用环境

- Apple Silicon（M 系列）Mac，macOS 14 或以上；当前只在 M1 / macOS 26.6.2 实测。
- 需要 Apple Command Line Tools，包含 Swift 编译器与 Python 3；不要求购买开发者会员，也不要求安装完整 Xcode。
- 源码本身没有第三方依赖；编译过程不下载依赖。首次安装 Apple 开发工具需要联网。

## 编译与安装

1. 解压 FileSearch-v0.10-source.zip，将文件夹放到自己可以读写的位置。
2. 打开“终端”，先执行：

```sh
xcode-select --install
```

按系统提示完成安装。如果提示已经安装，可继续。若工具安装由公司管理，请联系管理员。

3. 在终端输入 `cd `（cd 后有一个空格），将解压后的 FileSearch-v0.10-source 文件夹从 Finder 拖到终端中，按回车。然后执行：

```sh
python3 app/build.py
```

等待编译结束。成功时最后一行会显示生成的 FileSearch.app 的路径。如果出现编译错误，请保留完整错误文字，不要继续安装。

4. 在该源码文件夹中找到 `app/dist/FileSearch.app`。先退出原来运行的文件搜索，再把新生成的应用拖入“应用程序”文件夹。需要替换已有副本时，由本人在 Finder 确认。
5. 双击新生成的应用。在“设置→添加目录”中选择自己的搜索目录。最初仅收录自动生成的示例文件。

在本机从源码生成应用，可用于开发试用，但不是苹果公证，也不能保证避开设备管理或全部系统安全检查。若仍然被拦截或打不开，请提供系统提示与编译输出。不要把本机生成的应用当作已公证成品转发给别人。

## 使用

- 名称可输入多个词；后缀输入 x、xl 即可匹配 xlsx，支持多后缀及只按后缀搜索。
- 设置可启用常驻桌面搜索窗，保留背景透明度、玻璃和实色模式。
- 单击选中、双击打开；右键提供打开、复制路径、在 Finder 中显示。
- 设置里的路径详情只影响主窗口。
- 关闭主窗口后后台仍运行；从菜单栏退出。
- 本版本已取消系统小组件。当前没有完整全盘引导与权限恢复流程。
- 索引与设置保存在 `~/Library/Application Support/LocalFileSearch/`；应用没有联网功能。

## 可选验证

在上述源码文件夹中执行：

```sh
python3 app/test.py --layout
```

测试只生成源码文件夹内的隔离样例，报告保存在 app/results。查看报告中的 automatic_fsevents_tested；若为 false，不能认为文件自动同步已经通过测试。

若需要验证本机打包、解压和启动：

```sh
python3 app/package.py --launch
```

生成的 ZIP 仍为本机临时签名、未公证的开发包。

本包用于接收者本机编译试用。目前尚未选定公开开源许可证；如果后续发布到 GitHub 作为开源项目，应由作者明确选择许可证。
