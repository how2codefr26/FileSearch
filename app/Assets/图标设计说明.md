# FileSearch 应用图标设计说明

日期：2026-10-21，对应 v0.10。

## 概念

“文件夹 + 搜索镜 + 向前的动势”。青色文件夹表达本地文件与目录；白色搜索镜明确传达查找；向右下伸出的镜柄与文件夹内部斜向留白形成动势，呼应即时检索。深蓝圆角底座提供稳定、安静的工具感，青绿色让图标在桌面与 Finder 中易于区分。

不在图标中加入文字、AI、云端或系统小组件图形，以免暗示尚未提供的能力。当前继续沿用 FileSearch 名称。

## 资源与应用

- Assets/AppIcon.png：生成的透明背景彩色图标母版，1254×1254，RGBA。
- build_icons.py：使用 macOS 自带 sips 与 iconutil，生成标准多尺寸 ICNS。
- 尺寸：16、32、128、256、512 点，各含 1× 与 2×，覆盖至 1024 像素。
- 构建产物：Contents/Resources/AppIcon.icns，通过 Info.plist 的 CFBundleIconFile 应用于应用图标。
- 菜单栏使用 MenuBarIcon.swift 自绘的文件夹与搜索镜组合，18 点矢量模板图像随系统明暗主题适配。悬停提示“文件搜索 · FileSearch”，不再使用与 Spotlight 相似的单独放大镜。
- 图标 PNG 和转换脚本纳入源码包，其他人本机编译也能得到相同应用图标。

已检查 32 和 128 像素缩略图，并通过 macOS 原生应用图标接口读取新构建，确认系统返回新图标。图标为本次生成设计，未进行商标注册或独占性检索。
