# 路线图与验收边界

这些是待完成工作，不是已实现功能；暂无承诺发布日期。

## 优先：范围与可靠性

- 收录范围引导、权限拒绝／收回／恢复，显示各范围覆盖、缺口和最后核对时间。
- 根目录迁移、卷身份、休眠恢复、历史事件丢失和通知不可用时的恢复验证。
- SQLite 损坏与写入错误恢复、崩溃注入及缓存一致性验证。
- 大目录分批收录，限制扫描峰值内存；合并密集变化，减少全量快照重写。

## 优先：分发与兼容

- Developer ID 签名、Hardened Runtime、苹果公证及真实下载来源的首次安装验收。
- macOS 版本、输入法、多屏、桌面空间、VoiceOver、快捷键冲突及实际硬件触发矩阵。
- 实测冷启动、界面可见时间、唤出耗时和不同规模下的 P50／P95；区分合成与真实目录。
- 明确公开开源许可证、贡献授权和后续版本分发方式。

## 待评估扩展

- 文件内容预览；按需开启并保持简洁布局。
- 外置磁盘、网络卷、云盘占位文件的明确支持范围。
- Intel／Universal 构建；当前只有 Apple Silicon 目标。

系统 WidgetKit 小组件已取消，当前不将其作为已交付能力或既定重建计划。全文搜索、复杂搜索语法、批量文件处理和在线服务也尚无承诺。
