# 实现架构

## 模块

| 文件 | 职责 |
| --- | --- |
| `app/Sources/main.swift` | 创建 AppKit 应用与生命周期入口 |
| `Application.swift` | 设置、目录选择、菜单栏、快捷键、登录项和退出协调 |
| `Interface.swift` | 主／桌面搜索窗口、原生列表、筛选排序及文件动作 |
| `DesktopSurface.swift` | 玻璃与实色背景、透明度与外观适配 |
| `ModelSearch.swift` | 名称规范化、后缀解析、目录枚举、快照读取和检索排序 |
| `Store.swift` | SQLite 状态、事务核对、事件检查点及快照写入 |
| `IndexService.swift` | FSEvents、变化合并、首次扫描、暂停恢复和历史事件处理 |
| `Preferences.swift` | JSON 偏好、旧字段兼容、透明度范围约束 |
| `MenuBarIcon.swift` | 自绘文件夹与搜索镜模板图像 |

## 索引数据链

用户主动添加目录后，后台串行索引队列枚举名称、路径、类型、修改时间与设备／inode 身份。SQLite 是持久化事实来源；完成事务后生成版本化二进制快照并原子替换。查询通过内存映射读取紧凑快照，减少重复字符串分配。

快照验证魔数、版本、总长度、行大小、字段边界与父目录引用；缓存损坏可从 SQLite 重建。该能力不等于 SQLite 数据库损坏后的完整恢复，后者尚未完成。

扫描不跟随符号链接、不深入软件包，目录按身份去重，硬链接的不同路径保留。固定排除自身状态目录。当前范围限于内置本地设备；跨设备子目录被跳过并记录缺口。

## 变化同步

FSEvents 在扫描前建立监听，通知汇聚为需要重新核对的父目录。约 150 ms 合并窗口，过多待处理目录会退化为根范围核对。丢事件、根变化等标志会扩大核对范围。

批次内目录事务完成后再推进事件检查点；暂停时累积待处理范围，继续后核对。重启利用保存的事件 ID 补录退出期间变化。通知不可用时显示提示并允许手动重新核对。休眠、根迁移、历史事件丢失组合和大量写入仍需压力验收。

## 搜索与界面

输入变化在后台查询队列约 15 ms 后调度，取消门使旧查询失效，避免过时结果覆盖新输入。查询遍历完整快照，以所选根、类型、名称和后缀筛选，全量计数并保留排序后的前 N 项，N 最大 500。

名称先做 NFC 与 ASCII 大小写归一化，多词取 AND；多个后缀取 OR，按后缀链前缀判断。搜索不是正文索引，也不解析正则或布尔表达式。

主窗口和桌面窗共享索引与偏好，各有输入和展示。原生 `NSTableView` 提供虚拟化滚动。文件动作前核对身份，右键目标失效时禁止对旧对象继续操作。

## 当前工程权衡

- 当前名称检索为全量快照扫描，随数据规模增长；尚无针对任意子串的专用倒排索引。
- 首次扫描累积一个目录的条目；大范围的峰值内存尚未充分控制。
- 变化后重新生成全量快照，密集变化可能带来写放大。
- SQLite 持久化、文件访问缺口与系统权限不能被“范围已核对”概括成全盘覆盖。
- 应用包使用临时签名；尚无 Developer ID、公证及正式升级渠道。
