# 使用指南

## 安装与首次使用

推荐从 [Releases](https://github.com/how2codefr26/FileSearch/releases/tag/v0.11) 下载已编译 ZIP，解压后将 FileSearch.app 拖入“应用程序”，无需开发工具。首次打开可能受到系统安全检查，见[安装说明](INSTALLATION.md)。也可按 [README](../README.md) 从源码构建，生成 `app/dist/FileSearch.app`。退出旧实例后，可将应用拖入“应用程序”。初次启动只收录应用内自动生成的示例文件；在“设置 → 添加目录…”选择自己的内置磁盘目录后才开始收录。

应用移动后，原有示例路径可能失效；在设置移除旧示例范围，再添加实际需要的目录。当前尚无自动修复该路径的完整流程。

## 界面语言

在“设置 → 界面语言”中选择简体中文或 English，立即更新窗口、菜单、右键操作与状态提示，并保存选择。切换保留查询、类型／后缀／排序、窗口位置和收录暂停状态。文件名与路径不翻译；系统对话框可能跟随 macOS 语言。

## 名称和后缀

- 名称按字面子串匹配；以空格分开的多个词为 AND 关系，均需出现在名称中，不要求输入顺序。
- 后缀按每个非首位点号之后的后缀链前缀匹配。例如 `archive.tar.gz` 可匹配 `t`、`tar.g`、`gz`；`xl` 可匹配 `xls`、`xlsx`、`xlsm`。
- 多个后缀为 OR 关系，以逗号、分号、空格及中文逗号／分号分隔；可带一个开头的点号。
- 后缀留空不限格式；名称留空时可以仅按后缀搜索。两者都空时不展示全量条目。
- `*.pdf` 等通配符后缀不支持；直接输入 `pdf`。名称中的通配符和 `AND` 没有特殊搜索含义。
- 执行 Unicode NFC 规范化与 ASCII 大小写归一化；不承诺拼音、繁简转换、重音忽略或完整 Unicode 大小写折叠。

主窗口可以切换全部／文件／文件夹，按相关度、名称或修改时间排序。相关度大致优先完整名称、名称开头、连续短语及分散多词；同级再比较修改时间和路径。最多显示前 500 项，命中总数仍基于整个已收录集合。

## 打开与定位

单击只选中，双击打开；右键提供打开、复制路径和在 Finder 中显示。`↑↓` 选择、`Enter` 打开、`⌘Enter` 定位、`Esc` 收起主窗口。打开前会核对条目身份；文件已经被替换时需要重新核对。

全局快捷键 `⌃⌥Space` 已实现，但各环境冲突与硬件触发仍需验证；不可用时从菜单栏打开。关闭主窗口不结束进程，完全退出使用菜单栏“退出文件搜索”。

## 常驻桌面搜索窗

在设置开启“显示常驻桌面搜索窗”。它只包含搜索框和结果列表；类型、后缀、排序和设置入口保留在主窗口／菜单栏。主窗口路径详情开关不会向桌面窗加入详情面板。

可选紧凑／标准／宽松行高；开启毛玻璃时，0–70% 透明度只改变背景，文字与图标保持不透明。关闭毛玻璃使用实色，透明度滑杆暂停生效。系统减少透明度设置会触发实色回退。此窗口不是 macOS 系统小组件。

## 收录目录

设置支持添加／移除目录、“重新核对”和暂停／继续收录。只接受内置本地磁盘目录，不跨其他设备遍历、不跟随符号链接、不展开软件包内部。被权限阻止的位置会产生访问缺口。

“范围已核对”只表示当前已选范围本次核对完成，不表示整机全部文件都已收录。暂停期间结果可能过期；通知不可用时应手动重新核对。移除搜索范围会移除对应索引，不删除原文件。

登录时启动由设置开关主动开启；源码构建的应用在不同机器上的系统注册与权限仍需验证。

## 常见问题

| 情况 | 检查方式 |
| --- | --- |
| 找不到文件 | 确认目录已添加、收录完成、文件名条件与后缀符合，目录可访问；尝试重新核对 |
| 新文件没有出现 | 确认未暂停；查看通知不可用或访问缺口提示；手动重新核对 |
| 结果过多 | 增加名称词或后缀，当前最多展示前 500 项 |
| 软件移到别处后示例失效 | 移除旧示例目录，添加实际搜索目录 |
| 关闭窗口后还在运行 | 这是菜单栏常驻程序，从菜单栏退出 |
| 系统阻止启动 | 当前未公证；保留提示与构建输出，按设备管理要求处理，不修改系统安全策略 |
| 同时出现多个实例 | 正常用应用包启动；直接多次执行二进制可能启动多个实例，先退出测试实例 |

## 更新与移除

更新前退出旧应用，再替换应用包。设置与索引默认保存在 `~/Library/Application Support/LocalFileSearch/`，不在应用包内。需移除软件时先退出并由本人关闭已开启的登录项；保留或清理数据目录前自行备份，该目录可能包含敏感文件名和路径。
