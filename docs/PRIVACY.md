# 隐私与安全说明

## 应用处理的数据

FileSearch 枚举用户添加目录中的文件名、路径、类型、修改时间及文件身份，保存 SQLite 索引、搜索缓存和 JSON 设置。它不做正文全文索引，无账号登录、联网请求、遥测或云端查询功能。

默认数据目录是 `~/Library/Application Support/LocalFileSearch/`；`--state` 可指定开发测试位置。名称和路径可能透露个人信息，即使没有正文，也请将该目录按敏感本机数据管理。本项目没有提供应用层数据库加密功能。

添加目录由系统目录选择器完成，仍受 macOS 权限控制。项目没有完整权限恢复向导。登录启动由用户开关控制，不会在构建或测试时自动开启。

## 文件操作边界

打开和在 Finder 中显示会调用系统及默认应用；复制路径会写入剪贴板。外部应用的联网、同步和文件处理不由 FileSearch 控制。移除索引范围不删除原文件。

## 仓库上传范围

包含 Swift 源码、Python 脚本、测试源码、应用图标、说明和合成数据生成器。版本库不包含本机索引、偏好、证书、密钥、构建缓存、测试生成目录或开发机原始日志。已编译应用作为 Releases 附件单独提供，只含程序、图标、生成示例与使用说明。

`.gitignore` 用于降低误提交风险，但不能代替提交前审查。报告问题时请使用虚构样例，遮盖个人文件名、用户名和完整路径；不要上传索引数据库。

## 分发状态

本机临时签名用于开发验证，不是苹果 Developer ID 签名或公证。当前提供公开测试包下载；跨机器首次安装、升级和完整兼容矩阵仍待验证。下载应用不需要开发工具，但尚未完成公证，首次打开可能受到系统拦截。

发现可能涉及敏感数据的问题时，请勿在公开 Issue 中粘贴可利用细节、个人数据或凭据。可先用不含敏感信息的 Issue 请求与维护者建立私下沟通渠道；当前未配置专门安全联系邮箱和响应时限。
